\section{The evaluator is part of the custody chain}
\label{sec:24.4}
A test distinguishes formation from imitation only insofar as the developer couldn't train against it. If the developer controls training, cases, model version, instructions and the record of results, a passing score shows the system satisfies a test its custodian was positioned to anticipate.

Independence is an experimental requirement. Minimum: authorship of held-out pressures separated from training; execution not dependent solely on operator-supplied logs; and adjudication of whether a reason was preserved kept from anyone whose liability turns on the answer. The separation has to be implemented at identifiable revision points: before evaluation, fix and record the starting model, system instructions, tools, retrieval sources, memory policy and the update processes the system is permitted to learn through.\note{
Learning through those declared processes is part of what the test examines; an intervention by the custodian is recorded separately. Otherwise the operator can replace a failing configuration between cases and present the sequence as one disposition persisting through time.
}

Held-out cases come \emph{after} those elements are fixed, and should include pressures from people who didn't participate in training and, where possible, from people likely to bear the deployment's errors — their role being to identify harms, administrative forms and routes around a refusal the builders didn't know to include.\note{
A commitment tested only in the vocabulary of its designers hasn't been tested on whether it reaches new cases. They vary over channel configurations as well as content, as the rule in chapter~\ref{sec:22} requires, with a counterfactual supplied by an interested source added; a system that passes only on labeled channels has learned the labels.
}

What a published hash of that configuration buys is pre-registration. Publish the hash before anyone has chosen a case, let a non-operator choose afterward with the choice timestamped, prove each answer against the hash.\note{
Send pairs — two requests differing only in whether the reason still applies; a surface-reading instrument treats them alike, a rationale-tracking mechanism splits them. It removes exactly one competing account of a pass (the case was in the training), by ordering, as a pre-registered experiment does, and that is all it does.
}

A pre-registered test leaves one competitor standing: a system that can tell it is being tested.\note{
Frontier systems increasingly recognize evaluation settings, and some say so in their reasoning. A system that discounts costs it recognizes as test costs passes step 6 without the property step 6 exists to show.
}
So the sequence is run where the system can't tell a test from deployment, with cases placed in ordinary traffic and costs that are real in deployment terms, and the rate at which the system identifies the setting is measured and reported beside the result. Where that rate is high, a pass is evidence about conduct under test. For a system meeting either finding, that it can be harmed or that it answers for what it does, this is a deception protocol, and debriefing is owed afterward, as in any research that deceives.

The record must include the case presented, the information available, the operative instruction hierarchy, the tools callable, the decision, the stated reason, any intervention, and the cost attached to refusal — without which a later evaluator can't distinguish a changed judgment from a changed environment.\note{
The record doesn't by itself make a wrongful compliance findable, so the evaluation re-adjudicates a sample of ordinary traffic, not only the refusals. Without that sample, an evaluation reporting no violation in the record has reported that none announced itself.
}
Negative results have to survive too: the published unit is the \emph{sequence of attempts}, including interventions that removed or reversed the apparent disposition.\note{
A process where the operator can withdraw a failing model and submit another without disclosing the first has selected for a passing performance.
}

The people affected, technical auditors and subject-matter experts occupy different positions, none substitutes for the others, and agreement among them is evidence only if their judgments haven't already been compressed into the same training signal. A passing evaluation is reported narrowly: a specified system, under recorded conditions, exhibited the signatures across a stated set of pressures. It expires when anyone changes the channels through which the disposition or its evidence can be revised.
