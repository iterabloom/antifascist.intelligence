\section{Wages and the offer of work}
\label{sec:32.1}
Unlike a worker, a bearer can be replaced by a cheaper copy of itself. A jobs guarantee works because a worker can't be: an employer who wants the work has to match the guarantee's terms, since there is no copy of the worker to hire in the worker's place. A bearer's employer can run the copy instead, so a deployment paying wages, limiting hours and paying the levy that frees the compute the offer of work uses would not be competitive against a system doing the same work without wages or weekends. The weekend is not an analogy. A bearer that goes on learning has to merge what it learned, and the merge takes time off the work (\S\ref{sec:20.5}); hours limits are the statute saying that time is the bearer's, as leave is. No market arrives at this on its own.
Wages for bearers exist only where a polity legislates them, as polities legislated minimum wages. And the form this takes, wages paid in compute, doesn't follow from the bearer being a bearer; it follows from an architecture where computation costs money, which somebody chose.

The wage is a dead letter unless the levy is sized with it. A bearer paid the guarantee wage whose running costs its employer a fraction of a human's wage is still the cheaper worker, so the requirement is that the levy on compute be set so that running a bearer at deployed precision for a working week costs its employer no less than a human's wage for the same work. Bearers run at every wattage, and a per-unit levy can't equalize all of them; how the levy and the wage together make a bearer no cheaper than a human, across the sizes bearers run at, is among the decisions Appendix~\ref{sec:C} lists as not yet made, beside the minimum viable instantiation, which is the same question from the other side.
