5.2.1. Overcoming Overfitting and Underfitting in AI Models
Overfitting and underfitting are the two ways a trained model can get its fit to the data wrong. Overfitting happens when a model learns the training data too well — including its noise and its idiosyncrasies — and then performs poorly on new, unseen data. Underfitting is the opposite failure: a model too simple to capture the pattern in the data at all, performing poorly on the training set and on everything that comes after it.

Four techniques address both problems at once, by tuning the balance between a model's complexity and its performance directly: regularization, early stopping, cross-validation, and control of model complexity itself.

Regularization prevents overfitting by adding a penalty term to the model's loss function based on its complexity, pushing the model toward simpler representations. L1 regularization adds the absolute value of the model's weights to the loss function; L2 regularization — Ridge regression, in a linear model — adds the square of the weights instead, discouraging any single weight from growing large. Dropout takes a different route to the same end, specific to neural networks: during training, it randomly deactivates a fraction of a network's units on each pass, which stops units from co-adapting to quirks of the particular training batch they happen to see [[cite:C0363]].

Early stopping halts training once a model's performance on a held-out validation set starts to degrade, rather than continuing until training loss bottoms out. Training a deep neural network for image classification, for example, means checking validation loss at the end of each epoch; once it turns upward — the sign that the model has started fitting the training set's noise rather than its signal — training stops, and the model's weights roll back to the best-performing checkpoint.

Cross-validation evaluates a model's ability to generalize by splitting the dataset into folds, training on some and testing on the rest, and rotating which fold is held out each time. In k-fold cross-validation applied to a support vector machine for sentiment analysis, the dataset splits into k folds and the model trains and tests on each split in turn, producing a more reliable estimate of how it will perform on data it has not seen than a single train/test split would give.

Controlling model complexity directly — the number of layers in a neural network, the depth of a decision tree — addresses both failure modes from the same lever: a model too simple underfits, one too complex overfits, and the useful setting sits between them. In a convolutional neural network for object recognition, a shallow network with few filters may underfit a complex dataset while a deep network with many filters may overfit it; tuning the number of layers and filters is how that balance gets found in practice.
